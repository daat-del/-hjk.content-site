"בעשרה מאמרות נברא העולם" – הדיבור כחומר גלם המשנה במסכת אבות (פרק ה', משנה א') קובעת:  "בַּעֲשָׂרָה מַאֲמָרֹות נִבְרָא הָעוֹלָם. וּמָה תַּלְמוּד לוֹמַר, וַהֲלֹא בְּמַאֲמָר אֶחָד יָכוֹל לְהִבָּרְאוֹת? אֶלָּא לְהִפָּרַע מִן הָרְשָׁעִים שֶׁמְּאַבְּדִין אֶת הָעוֹלָם שֶׁנִּבְרָא בַּעֲשָׂרָה מַאֲמָרֹות, וְלִתֵּן שָׂכָר טוֹב לַצַבריאה בכל יום מחדש.
